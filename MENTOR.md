# Mentor Access

Our supervisor/mentor has **Admin** access to this repository for oversight, review, and guidance throughout the project.

This access allows the mentor to:
- View all code, pull requests, issues, and commit history across every module
- Review and comment on progress at each checkpoint
- Adjust branch protection rules or repository settings if needed

The mentor is not an active contributor to the codebase — commits and pull requests are made by the five team members listed in `README.md`, each owning one module.
